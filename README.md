# everypen-host
> The pen to use everywhere* for everything**.

To run on the host computer that effectively acts as the display for the everypen.

## API:
There should only need to be communication from the everypen to the host. The information should be:
 - Relative coordinates from the center
 - "Re-center" action (knob push)
 - Knob twist right, knob twist left
